# Kilder for GT Maskin-demoen

Samlet 22.-24.09.2026. Dagens nettside (gtmaskin.com) blokkerer automatisk henting, så teksten er hentet fra søketreff og fra Facebook-snippet. Alt som ikke er verifisert står som plassholder.

| Fil | Innhold |
|---|---|
| `FAKTA.md` | Verifiserte fakta: org.nr., adresse, åpningstider, kontakt, roller, godkjenninger, kanaler. Eneste kilde for fakta. |
| `INNHOLDSKART.md` | Dagens sidestruktur og den nye. |
| `INNHOLD-RAATEKST.md` | Del A: kundens egne tekster ordrett (med stavefeil). Del B: ferdig ny sidetekst per seksjon, klar til `src/data/`. |
| `RESSURSER.md` | Bilder, video, integrasjoner, skjemaer, eksterne sider, og hva som ligger i `assets-raw/`. |
| `SOME-FEED-EKSEMPLER.md` | Hvordan feed-kortene fylles nå (plassholdere) og hvordan ekte innlegg legges inn. |
| `DESIGNSYSTEM-GTMASKIN.md` | Palett med tokens, typografi, komponenter, seksjonsrytme. |
| `INTEGRASJONER-GTMASKIN.md` | Datastrukturer for `src/data/`: feed, video, reviews, kanaler, biler, produkter, utleie. |
| `design/reference-desktop.html` | Godkjent visuelt utkast, desktop 1440. Åpne i nettleser eller les som HTML. |
| `design/reference-mobile.html` | Godkjent visuelt utkast, mobil 390. |

Referansefilene viser design og seksjonsinnhold. Seksjonsrekkefølgen på forsiden er oppdatert i `PROMPT.md` punkt 4 (feed og video flyttet høyere opp som ny verdi) og gjelder foran referansen.

## Hva som er verifisert og ikke

Verifisert mot kilde: alt i `FAKTA.md`.

Ikke verifisert, skal stå som plassholder: priser (utleie, deler, biler), ansatte ut over Gjermund Thomassen, milepæler etter 2012, anmeldelser og rating, følgertall ut over «ca. 1 023 liker siden» (snippet), videoer, alle bilder.

## Kjente avvik du skal håndtere

- Kildeteksten har stavefeil (reperasjon, amrikanske, rustene, ett bilverksted). Behold ordlyden, rett stavefeilene, list dem i `BESLUTNINGER.md`.
- Proff oppgir forretningsadresse Bakkeveien 14, mens verkstedet ligger i Myggveien 3. Bruk kun Myggveien 3 på siden.
- Tre telefonnumre er funnet. Bruk 911 14 628 (fra kundens egen nettside). De to andre står i `FAKTA.md` til avklaring.
